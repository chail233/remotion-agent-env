# scene/ — 场景外壳与画面框架

背景 / 整章外壳 / 圆角面板三件，可任意单用或组合；位置尺寸均由 props 决定，本分类不预设版面。

| 编号 | 文件 | 角色 | 长什么样 |
|---|---|---|---|
| scene/01 | Paper.tsx | 背景 | 米白底 + 48px 淡棕方格线，铺满全屏（目前仅此 1 款，换底色传 `tint`） |
| scene/02 | Scene.tsx | 外壳 | 上面 01 打底 + 开场章节大卡片 + 左上衣帽徽页眉 + 首尾淡入淡出 |
| scene/03 | Stage.tsx | 面板 | 半透明奶白圆角矩形 + 细棕描边，默认 (1060, 90, 800, 850)，位置尺寸由 props 决定 |

## 01 Paper.tsx — 纸张背景

导出 `Paper`。依赖 `./theme`。`tint` 可换底色。Scene 已自带，也可单独铺。

## 02 Scene.tsx — 章节外壳

导出 `Scene`。依赖 `./theme`（内联了 Paper 背景和弹簧弹出，单拷本文件只需 theme）。

```tsx
<Scene no="3" title="小标题" duration={900} brand="角标文字">…正文…</Scene>
```

| 属性 | 说明 |
|---|---|
| `no` | 章节号字符串（渲染成「第 N 章」+「CHAPTER N」） |
| `title` | 章节标题 |
| `duration` | 本章总帧数，用于结尾淡出 |
| `intro` | 默认 true：播放开场章节大卡片（第 0~62 帧） |
| `brand` | 右上角小字，传 null 隐藏 |

**时间轴硬约定**：正文在第 52~66 帧淡入，页眉第 54~70 帧滑入。`intro=true` 时**场景内动画从第 60 帧之后开始排**；不需要卡片就传 `intro={false}`，从 0 帧起排。

## 03 Stage.tsx — 舞台面板

导出 `Stage`。依赖 `./theme`。默认 (1060, 90, 800, 850)，`bg` 可换底色。

- 内部坐标相对舞台左上角
- `overflow: hidden`：超出舞台的内容会被裁掉，**飞出画面的动画元素要放在 Stage 外面**
